# 家滾滾 開發路線圖

版本 0.1｜2026-10-16


## 1. 第 0 階段：基礎建置（本次完成）

1. 工具鏈：Godot 4.7.2、Blender 5.2.2 LTS（bpy）、Python 音效合成、粉圓字型。

2. 遊戲設定文件、原作研究報告、技術文件。

3. 核心玩法：雙搖桿坦克操作、滾動物理、吸附、體積成長、撞擊掉落、突出點、尺寸門檻、追蹤鏡頭。

4. 內容：「家」場景（騎樓、客廳、廚房餐廳、後院）、63 種物件、第 1 與第 2 關可完整遊玩。

5. 介面：標題、關卡選擇、收藏目錄、操作說明、暫停、遊戲中介面、結算與講評。

6. 品質：單元測試、流程測試、自動遊玩平衡測試、自動截圖、匯出封包驗證。


## 2. 第 1 階段：手感與第一印象（建議下一步）

| 項目 | 內容 | 目的 |
| --- | --- | --- |
| 真人試玩 | Terix 實際玩第 1、2 關，記錄卡關點與手感 | 自動測試無法取代的感受 |
| 凹凸滾動 | 大物件黏上後讓球體滾起來歪斜 | 原作最有辨識度的手感之一 |
| 鏡頭里程碑 | 比較「連續拉遠」與「尺寸跳段拉遠」，加入遮擋物半透明 | 家具底下的視野 |
| 第一人稱環視 | 對應原作 L1 | 找隱藏物件 |
| 會動的生物 | 貓（小時追你、大時逃跑）、蟑螂、蚊子 | 原作的幽默與壓迫感 |
| 模型替換 | 把家裡 60 多件物件逐步換成 Blender 模型 | 美術一致性 |
| 正式音樂與音效 | 作曲委託或授權音源 | 情緒與節奏 |
| 星婆婆演出 | 開場委託與結算講評的角色立繪或 3D 演出 | 敘事與個性 |


## 3. 第 2 階段：走出家門（第 3、4 關）

1. 第 3 關「街角公園」：10cm 到 50cm，溜滑梯、鞦韆、沙坑、路邊攤小物。

2. 第 4 關「家與巷口」：5cm 到 1m，重用「家」並開放大門、騎樓、巷口；家具在這關開始可以被捲起來。

3. 技術：場景分區載入、大型家具捲起時的物理處理、MultiMesh 大量遠景物件。


## 4. 第 3 階段：放大到城市與島嶼（第 5 到第 10 關）

1. 尺度系統：分層場景、世界重新縮放、浮動原點（見技術文件第 11 章）。

2. 內容：市場與商店街、學校與廟埕、河濱、小鎮、城市、整座島。

3. 收集要素：類似原作「禮物」與「表兄弟姊妹」的原創隱藏要素（例如可替換的小滾服裝、可操作的親戚角色）。


## 5. 第 4 階段：發行準備

1. 設定選單：音量、鍵位重設、鏡頭速度、畫質。

2. 多語系：繁體中文、英文、日文。

3. 無障礙：色弱友善配色、字體大小、操作輔助。

4. 匯出與發行：Windows、macOS 簽章與公證；若上架 Steam，整合成就與雲端存檔。

5. 智財審查：上市前由律師檢視名稱、角色、介面與宣傳素材。


## 6. 需要 Terix 決定的事項

見《01_遊戲設定文件》第 14 章：場景風格、正式名稱、個人作品或商業發行、美術與音樂的製作方式、目標平台。
