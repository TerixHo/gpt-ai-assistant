# 家滾滾 開發路線圖

版本 0.2｜2026-10-16（兒童版）


## 1. 第 0 階段：基礎建置（本次完成）

1. 工具鏈：Godot 4.7.2、Blender 5.2.2 LTS（bpy）、Python 音效合成、粉圓字型。

2. 遊戲設定文件、原作研究報告、技術文件。

3. 核心玩法：雙搖桿坦克操作、滾動物理、吸附、體積成長、撞擊掉落、突出點、尺寸門檻、追蹤鏡頭。

4. 內容（0.1 版，已由兒童版取代）：台灣透天厝場景、63 種物件、兩關可玩。

5. 介面：標題、關卡選擇、收藏目錄、操作說明、暫停、遊戲中介面、結算與講評。

6. 品質：單元測試、流程測試、自動遊玩平衡測試、自動截圖、匯出封包驗證。


## 1.1 第 0.5 階段：兒童版（本次完成）

1. 目標玩家改為小學生：簡單操作預設、注音模式、不限時間模式、溫和的失敗與鼓勵式講評。

2. 場景改為原創的日式一般家庭一樓：客廳學習角（姊姊與弟弟的書桌）、LDK、和室、玄關、走廊、洗面所、木平台與小花園。

3. 從 1.2 公分的滾球、6 到 8 公釐的玻璃珠開始，156 種物件逐級放大，以文具與小玩具為主。

4. 三毛貓與柴犬：會閒逛、會拍掉東西、會逃跑、夠大可以黏起來。

5. 三關可玩（書桌、客廳、全家），自動遊玩驗證過關率。

6. Blender 模型增加到 33 個（32 種物件加上推球角色）。


## 2. 第 1 階段：手感與第一印象（建議下一步）

| 項目 | 內容 | 目的 |
| --- | --- | --- |
| 小學生試玩 | 請 3 到 5 位不同年級的小學生實際玩第 1 到 3 關，觀察卡關點、注意力、挫折感與注音模式的可讀性 | 自動測試無法取代的感受 |
| 選角色 | 讓小朋友選「姊姊」或「弟弟」推球 | 代入感 |
| 凹凸滾動 | 大物件黏上後讓球體滾起來歪斜 | 原作最有辨識度的手感之一 |
| 鏡頭里程碑 | 比較「連續拉遠」與「尺寸跳段拉遠」，加入遮擋物半透明 | 家具底下的視野 |
| 第一人稱環視 | 對應原作 L1 | 找隱藏物件 |
| 更多會動的東西 | 倉鼠、金魚缸、會跑的玩具車；貓會跳上沙發與貓跳台 | 驚喜與幽默 |
| 模型替換 | 把其餘 120 多件物件逐步換成 Blender 模型 | 美術一致性 |
| 正式音樂與音效 | 作曲委託或授權音源 | 情緒與節奏 |
| 星婆婆演出 | 開場委託與結算講評的角色立繪或 3D 演出 | 敘事與個性 |
| 測試機器人會繞路 | 自動駕駛改用導航網格（NavigationMesh）規劃路線，能繞過書桌與廚房後檯 | 讓平衡數字從「粗略下限」變成可靠的量尺 |


## 3. 第 2 階段：走出家門（第 4、5 關）

1. 第 4 關「家門前的巷子」：20cm 到 2m，打開大門，巷子裡有腳踏車、盆栽、自動販賣機旁的小東西；家具在這關開始可以被捲起來。

2. 第 5 關「公園」：50cm 到 5m，溜滑梯、鞦韆、沙坑。

3. 技術：場景分區載入、大型家具捲起時的物理處理、MultiMesh 大量遠景物件。


## 4. 第 3 階段：學校、小鎮與島嶼（第 6 到第 8 關）

1. 尺度系統：分層場景、世界重新縮放、浮動原點（見技術文件第 11 章）。

2. 內容：學校（教室、操場、鞋櫃）、小鎮、整座島。

3. 收集要素：類似原作「禮物」與「表兄弟姊妹」的原創隱藏要素（例如可替換的小滾服裝、可操作的親戚角色）。


## 5. 第 4 階段：發行準備

1. 設定選單：音量、鍵位重設、鏡頭速度、畫質。

2. 多語系：繁體中文、英文、日文。

3. 無障礙：色弱友善配色、字體大小、操作輔助。

4. 匯出與發行：Windows、macOS 簽章與公證；若上架 Steam，整合成就與雲端存檔。

5. 智財審查：上市前由律師檢視名稱、角色、介面與宣傳素材。


## 6. 需要 Terix 決定的事項

見《01_遊戲設定文件》第 14 章：場景風格、正式名稱、個人作品或商業發行、美術與音樂的製作方式、目標平台。
