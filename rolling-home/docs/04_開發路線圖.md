# Gǔn A Gǔn A 開發路線圖

版本 0.4｜2026-10-17（第四版：冬山四關）


## 1. 第 0 階段：基礎建置（已完成）

1. 工具鏈：Godot 4.7.2、Blender 5.2.2 LTS（bpy）、Python 音效合成、粉圓字型。

2. 遊戲設定文件、原作研究報告、技術文件。

3. 核心玩法：雙搖桿坦克操作、滾動物理、吸附、體積成長、撞擊掉落、突出點、尺寸門檻、追蹤鏡頭。

4. 內容（0.1 版，已由兒童版取代）：台灣透天厝場景、63 種物件、兩關可玩。

5. 介面：標題、關卡選擇、收藏目錄、操作說明、暫停、遊戲中介面、結算與講評。

6. 品質：單元測試、流程測試、自動遊玩平衡測試、自動截圖、匯出封包驗證。


## 1.1 第 0.5 階段：兒童版（已完成）

1. 目標玩家改為小學生：簡單操作預設、注音模式、不限時間模式、溫和的失敗與鼓勵式講評。

2. 場景改為原創的日式一般家庭一樓：客廳學習角（姊姊與弟弟的書桌）、LDK、和室、玄關、走廊、洗面所、木平台與小花園。

3. 從 1.2 公分的滾球、6 到 8 公釐的玻璃珠開始，156 種物件逐級放大，以文具與小玩具為主。

4. 三毛貓與柴犬：會閒逛、會拍掉東西、會逃跑、夠大可以黏起來。

5. 三關可玩（書桌、客廳、全家），自動遊玩驗證過關率。

6. Blender 模型增加到 33 個（32 種物件加上推球角色）。


## 1.2 第 0.7 階段：網頁版、槿寶與集氣（已完成）

1. 網頁版：自行編譯單執行緒網頁引擎，iPad、手機、電腦瀏覽器直接玩；觸控搖桿與按鈕。

2. 主角換成槿寶（紫色貓咪），加入跳躍、第一人稱環視、五種視角、集氣衝刺（黃、橘、紅、藍色火焰）。

3. 3D 大標題與自動遊玩的示範背景。


## 1.3 第 1 階段：冬山四關（本次完成，0.4 版）

1. 故事搬到宜蘭冬山鄉：第 1 關槿寶的家（6 公分到 1 公尺）、第 2 關上學的路（1 到 3 公尺）、第 3 關小學與街區（3 到 10 公尺）、第 4 關滾到冬山火車站（10 到 100 公尺）。

2. 手感：白色粉彩核心、最後 10 件突出在外圍的不規則滾動、集氣慢慢推與至少 3 倍速、衝刺撞大東西反彈掉落、往前小跳與二段跳前空翻、台階自動滾上去、每個高處都有積木樓梯、卡住時回到中間、自動視角、成長歡呼。

3. 大尺度：重力隨大小放大、速度上限、鏡頭與主角隨尺寸放大。

4. 觸控按鈕改成圖示；搖桿放開再按住集氣。

5. 紅白機風格原創配樂五首、49 個音效、物件專屬音、槿寶的歡呼語音。

6. 效能：物件零件合併成單一網格、依大小設定可見距離。


## 2. 第 2 階段：試玩與手感（建議下一步）

| 項目 | 內容 | 目的 |
| --- | --- | --- |
| 小學生在 iPad 上試玩 | 請 3 到 5 位不同年級的小學生實際玩四關，觀察集氣手勢、卡關點、注意力、挫折感 | 自動測試無法取代的感受 |
| 聽音樂與音效 | 確認配樂、物件專屬音、槿寶的歡呼好不好聽、會不會太吵 | 開發環境無法播放聲音 |
| 成長歡呼頻率 | 依試玩感受調整里程碑間隔 | 太頻繁會吵、太少沒感覺 |
| iPad 效能 | 量測各關幀率；必要時降低物件數量或陰影 | 第 3、4 關物件多 |
| 測試機器人會繞路與爬樓梯 | 自動駕駛改用導航網格規劃路線 | 讓平衡數字更可靠 |
| 鏡頭遮擋 | 家具與建築擋住時半透明 | 視野 |
| 模型替換 | 把其餘物件逐步換成 Blender 模型 | 美術一致性 |
| 星婆婆演出 | 開場委託與結算講評的角色演出 | 敘事與個性 |


## 3. 第 3 階段：更多冬山（第 5 關以後，構想）

1. 第 0 關「書桌上的小珠珠」：把 0.2 版 1.2 公分起點的書桌關卡搬進槿寶家，給年紀最小的小朋友。

2. 第 5 關以後：蘭陽平原、海邊、整座宜蘭，滾到公里級；技術上要加浮動原點與遠景 MultiMesh（見技術文件第 11 章）。

3. 收集要素：類似原作「禮物」與「表兄弟姊妹」的原創隱藏要素（例如可替換的槿寶服裝、可操作的親戚角色）。


## 4. 第 4 階段：發行準備

1. 設定選單：音量、鍵位重設、鏡頭速度、畫質。

2. 多語系：繁體中文、英文、日文。

3. 無障礙：色弱友善配色、字體大小、操作輔助。

4. 匯出與發行：Windows、macOS 簽章與公證；若上架 Steam，整合成就與雲端存檔。

5. 智財審查：上市前由律師檢視名稱、角色、介面與宣傳素材。


## 5. 需要 Terix 決定的事項

見《01_遊戲設定文件》第 18 章：成長歡呼的頻率、要不要加回 1.2 公分起點的書桌關卡、個人作品或商業發行、美術與音樂的製作方式。
